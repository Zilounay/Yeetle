# Proofs of concept

Throwaway tryouts for risky technical questions (milestone "1 · POC"), one folder per tryout. They are never part of `Yeetle.slnx` and never referenced by the app. Once a question is answered, the result goes in its GitHub issue and the tryout is deleted.

**Exception: `ClipStrip` (#5) is kept on purpose.** Thumbnails were postponed, not dropped, and this tryout is where they restart from (see `docs/THUMBNAILS.md`). Do not delete it without asking ZiL first.

`Directory.Packages.props` here makes tryouts use the main solution's package versions.
